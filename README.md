# PIFOSE STORE

Ready for GitHub Pages.

## Upload
1. Extract this ZIP.
2. Upload ALL files and the `assets` folder to the root of `pifose-store`.
3. Click **Commit changes**.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Branch: `main` / Folder: `/(root)` → **Save**.

The storefront is static HTML/CSS/JS and does not require npm or a build step.
Prices and product names are demo storefront content until you replace them with your final catalog.
