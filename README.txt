PIFOSE ONE-FILE VERSION

This fixes the GitHub Pages image-path problem by embedding the CSS, JavaScript,
and product/campaign images directly inside index.html.

IMPORTANT:
1. In pifose-store, replace the OLD index.html with this NEW index.html.
2. Commit changes.
3. You do NOT need an assets folder for this version.
4. Wait for GitHub Pages to deploy.
5. Press Ctrl+F5 on the live site.

If GitHub asks whether to replace index.html, confirm the replacement.
